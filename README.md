# What's Happening?!

You probably found yourself here by typing a trust URL - "tw-modding.com" - into your browser nav bar or clicking a bookmark that's been reliable for some number of years that I can't even remember off the top of my head (seven years!).

Unfortunately, for the Time Being, I have taken the site down for some pretty major maintenance that it needs to undergo.

For now, this repository includes the backup of all pages and images from the website. I have more backup data available (and am willing to send it anyone's way who is interested), but I figured I'd pare down to the bare necessities for this public backup.

# Why?!

tw-modding.com was utilizing the version of PHP which had a major vulnerability announced this week. While there isn't much vulnerable data on the server itself, it was a vector for potential attacks, and could theoretically expose vulnerable data if the website was properly attacked. For years, I've been dealing with bot spam on tw-modding.com, which at one point was discovered as a MediaWiki website and joined the long list of sites that get regularly assaulted by spam/scam. I figured it was better to exercise caution than hope for the best.

Secondarily, I have grown dissatisfied both with the server host I've been using and with MediaWiki itself. Recently, I've set up a home server that I use for, e.g., the discord bot Grombot that we use in the Modding Den. My intention is to rebuild tw-modding.com on my own server. 

# What's Next?

I cannot intimate how much time it will take to set up the website once again, as the maintenance is fairly major and involves me learning a lot of new things. If there are any fairly competent sysadmin folks out there, please reach out with any pointers.
